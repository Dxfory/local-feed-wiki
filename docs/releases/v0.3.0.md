# 0.3.0

Draft release notes for 0.3.0, the first public version (2026-11-11).

The git tag and the GitHub Release are created separately. This draft does not create them.

## Highlights

- A local reader for RSS, podcast RSS, and YouTube channel Atom feeds. Offline runs read synthetic files under `examples/offline` and do not open a socket.
- Original bytes stay in `raw/`. The catalog is SQLite (`data/second_brain.sqlite` by default). While `data/run.lock` is held, a second run stops with `run_locked`.
- New items are classified in batches of at most 8 into must, recommend, and skip. When several sources touch one topic, review batches hold at most 4 topics and the minority page shows the library sentences side by side.
- Publish writes `wiki/digest/<run_id>.html`, `wiki/index.md`, and `wiki/snapshots/<run_id>/` (manifest, topic pages, and minority pages).
- A live completion call stays behind `live_authorized`, a verified `billing_path` of `session` or `api`, and `tool_policy_verified`, with `offline: false`. Offline completion is the checked-in file `tests/fakes/grok` via `SECOND_BRAIN_GROK`.
- URL checks reject non-global addresses, localhost, metadata host names, userinfo, credential query keys, and a fixed set of video-site hosts. They do not resolve DNS.
- Requires Python 3.13 or newer, `feedparser==6.0.14`, and `PyYAML==6.0.3`. GitHub Actions runs the offline suite on Python 3.13 and on Python 3.13.5.

## Install and quickstart

Python 3.13 or newer. Runtime packages are `feedparser==6.0.14` and `PyYAML==6.0.3`.

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install feedparser==6.0.14 PyYAML==6.0.3
PYTHONPATH=src SECOND_BRAIN_GROK=tests/fakes/grok \
  python3 -m second_brain.cli run --offline \
  --config-dir examples/offline \
  --now 2030-01-15T00:00:00Z \
  --db data/second_brain.sqlite
```

Open `wiki/index.md`, then the HTML path printed as `html=`.

`config/sources.yaml` is gitignored. Start a local copy from the public examples:

```bash
cp config/sources.example.yaml config/sources.yaml
cp config/preferences.example.md config/preferences.md
cp config/topic_aliases.example.yaml config/topic_aliases.yaml
cp config/runtime.example.yaml config/runtime.yaml
```

`config/sources.example.yaml` lists four public https feeds (Hacker News, BBC World, Planet Money, and the Google Developers YouTube channel). Offline mode rejects every non-file source, so those https feeds do not run under `--offline`.

A fetch uses `--live` and all of the following in `config/runtime.yaml`:

- `offline: false`
- `live_authorized: true`
- `billing_path` set to `session` or `api`
- `billing_path_verified: true`
- `tool_policy_verified: true`
- `SECOND_BRAIN_GROK` set to a regular file that is the completion binary

`--example-config` reads the tracked `*.example.*` files and does not write `config/sources.yaml`.

The project root is the checkout that contains `src/second_brain`. Override it with `--root PATH` or with a non-empty `SECOND_BRAIN_ROOT`.

## Known limitations

From the roadmap and the documented scope of this tree:

- A `check` command that validates config and prints hosts and budgets without fetching is not in this version.
- An OPML-to-YAML helper that writes to stdout is not in this version.
- Stricter source-list checks are not in this version: duplicate URLs, an empty list, and a cap on `backfill_days`.
- `wiki/latest.txt` is not written. Readers open `wiki/index.md` for the current digest and snapshot.
- Fetch-only operation without a completion call is not available.
- This tree has no vector index, web framework, background daemon, account, notification bot, or audio transcription. Scheduling stays outside the program. Audio enclosures are not requested.
- URL checks do not resolve DNS, so they are not a full SSRF defense.
- The minority page compares sentences already in the library. It is not a market conclusion, a position, or a target price.
