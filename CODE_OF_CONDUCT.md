# Code of conduct

This project is a local tool and a small code base. Discussion stays on the work.

## Expected

- Assume the other person is trying to ship a correct change.
- Comment on the code, the test, and the user-visible behavior.
- Issues and pull requests may be in English or 中文.
- Give someone room to correct a mistake.

## Not accepted

- Insults, harassment, or personal attacks.
- Posting someone else's private notes, credentials, or unlisted feed URLs.
- Asking the project to rank trades, name a position, or produce a target price. The minority page compares sentences already in the library.

## Reporting

Open a private security advisory, or contact the maintainers through the repository's private channel. Do not put the report in a public issue. Maintainers will remove the offending content and, if needed, block further participation.
